```eof Per l'installazione è fondamentale fornire anche i file giusti al browser (serve un'icona fisica che il browser deve poter leggere). Devi posizionare questi due file nella stessa cartella dell'`index.html`. ### Il file Manifest (manifest.json) Salvalo esattamente come `manifest.json`. Da notare che ora l'icona è `icon-192.png`. ```json:Genio Plus/manifest.json { "name": "Genio Plus", "short_name": "Genio+", "start_url": "./index.html", "display": "standalone", "background_color": "#f0fdfa", "theme_color": "#0d9488", "orientation": "portrait", "icons": [ { "src": "icon-192.png", "sizes": "192x192", "type": "image/png", "purpose": "any maskable" }, { "src": "icon-512.png", "sizes": "512x512", "type": "image/png", "purpose": "any maskable" } ] } ```eof ### Il file Service Worker (sw.js) Il service worker serve per far capire al browser che l'app "funziona anche offline" (requisito obbligatorio per l'installazione). Salvalo come `sw.js`. ```javascript:Genio Plus/sw.js const CACHE_NAME = 'genioplus-cache-v2'; const urlsToCache = [ './', './index.html', './manifest.json', './icon-192.png', './icon-512.png' ]; self.addEventListener('install', event => { self.skipWaiting(); event.waitUntil( caches.open(CACHE_NAME) .then(cache => { // Tentiamo di cachare tutto, ma non blocchiamo l'installazione se un'icona manca temporaneamente return Promise.allSettled(urlsToCache.map(url => cache.add(url))); }) ); }); self.addEventListener('activate', event => { event.waitUntil( caches.keys().then(cacheNames => { return Promise.all( cacheNames.map(cacheName => { if (cacheName !== CACHE_NAME) { return caches.delete(cacheName); } }) ); }) ); }); self.addEventListener('fetch', event => { // Passiamo sempre dalla rete per le chiamate API if (event.request.url.includes('generativelanguage.googleapis.com')) { return; } event.respondWith( caches.match(event.request) .then(response => { if (response) { return response; } return fetch(event.request); }) ); });
